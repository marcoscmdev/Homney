## Descripción

**Homney** permite a los usuarios de un mismo hogar:

- Gestionar y repartir tareas domésticas
- Registrar y compartir gastos comunes
- Optimizar la convivencia y los recursos del hogar

La arquitectura está basada en un **Webservice con API REST** que permite que la aplicación sea multiplataforma. La app Android consume la API mediante **Volley** para las peticiones HTTP y **GSON** para el parseo de JSON.
